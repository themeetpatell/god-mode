## Design philosophy

The system now has three layers:

1. **Model routing** — Haiku/Sonnet/Opus for cost and depth.
2. **Specialist agents** — domain behavior and output contracts.
3. **Skills** — reusable workflows that load only when relevant.

This keeps context small while expanding capability dramatically.
