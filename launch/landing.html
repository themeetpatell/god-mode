What's different

Five primitives nobody else has stitched together.

V

The verifier

Every other agent framework lets the worker grade its own homework. God Mode runs a separate verifier — tests run, sources fetched, voice scored, DAGs walked. "Shipped" stops being a claim.

R

Learning router

Weighted multi-signal pattern scoring, not string-includes() bingo. 100% accuracy on 104 stratified cases including 41 adversarial keyword traps. Gets sharper with every session via the ledger.

C

Context curator

Computes the minimum viable context per worker before delegation. Names files, glossary, decisions to preserve, what to drop. This is where the cost savings actually live.

M

Memory layer

Persistent ~/.themeetpatel/memory/ means session 10 is better than session 1. The CEO already knows your stack, ICP, voice rules, do-not list.

P

Domain Packs

Core engine + packs you install for your role. Founder-UAE, AI-builder, growth-ops, more. Localizes the CEO without bloating the global core.

H

Portable handoff

Start a goal in Claude Code, continue on phone in ChatGPT, finish in Cursor. The IP is the prompts, not the runtime. State travels.

How it works

One goal becomes a verified, routed, shipped deliverable in seven phases.

PHASE 1

Intake

CEO reads memory, restates goal, asks ≤3 clarifying questions only if memory doesn't already answer them.

PHASE 2

Roadmap

Phased plan with task IDs, dependencies, parallelism, model routing per task, token estimates.

PHASE 3

Routing

Each task gets Haiku, Sonnet, or Opus by weighted multi-signal scoring. Anti-pattern keyword traps don't fool it.

PHASE 4

Delegate

Context-curator computes the minimum context per worker. Workers spawn in parallel where independent.

PHASE 5

Verify

Separate verifier agent runs class-specific checks: code (tests + types), research (sources fetched), content (voice + specifics).

PHASE 6

Synthesize

Stitcher merges verified outputs. Failures are surfaced, not papered over.

PHASE 7

Ship

6-line exec summary: DONE / SHIPPED / VERIFIED / COST / TIME / NEXT. Ledger records the session for next time's learning.
