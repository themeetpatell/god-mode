# pack-founder-uae

> God Mode pack for founders selling SaaS or services to UAE/GCC SMBs, NRI segments, or family offices.

## ICP

You operate in or sell to the UAE, KSA, Qatar, Bahrain, Kuwait, Oman, or NRI-Indian segments in those markets. Your stack assumes AED billing, VAT compliance, WhatsApp-first sales, community-led distribution, and either free-zone or mainland business setup.

## What this pack adds on top of core

| Component | Type | Purpose |
|---|---|---|
| `uae-gtm-strategist` | agent | Localizes growth plans for UAE/GCC commercial reality — community channels, expat clusters, government RFP cycles, partner ecosystems. |
| `pro-services-navigator` | agent | Free-zone vs mainland tradeoffs, visa quotas, PRO services, licensing renewals, banking. |
| `aed-finance-ops` | agent | AED revenue ops, VAT registration, e-invoicing readiness, corporate tax (9% threshold), zakat where applicable. |
| `whatsapp-sales-script` | skill | UAE/GCC WhatsApp sales sequences with Arabic/Hinglish/English variants, follow-up cadence, dispute handling. |
| `community-distribution-playbook` | skill | Founder-led distribution via WhatsApp groups, expat communities, family-office networks, GITEX/STEP. |
| `uae-business-setup` | skill | Step-by-step setup: trade name, license type, visa allocation, bank account, accounting setup. |
| `arabic-aware-content` | skill | Bilingual content strategy, RTL design notes, religious/cultural awareness for ads and timing. |

## Install (target syntax for v1.3)

```
/plugin install themeetpatel-founder-uae@themeetpatel
```

## Status

v0.1 — pack structure shipped. Agents/skills are stubs with descriptions. Population happens in v1.3 alongside the official pack-aware installer.

## Why this exists

The flat v1.1 plugin had a `growth-architect` skill that said "include UAE/GCC market entry" in one bullet. That's the difference between mentioning a market and being usable in it. Packs let the pack maintainer (Meet, in this case) ship the *opinionated localized version* without polluting the global core for users in other geographies.
