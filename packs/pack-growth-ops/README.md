# pack-growth-ops

> God Mode pack for growth-ops practitioners running B2B SaaS or services GTM.

## ICP

You own a funnel. You run lifecycle. You answer to a CAC, an LTV, and a payback window. You want the CEO to default to "what does this cost to acquire, and what's the next experiment" instead of generic growth platitudes.

## What this pack adds

| Component | Type | Purpose |
|---|---|---|
| `funnel-diagnostics-lead` | agent | Reads funnel numbers, identifies the bottleneck stage, and prescribes a 30-day experiment plan. |
| `lifecycle-architect` | agent | Designs onboarding/activation/retention/expansion automations with trigger logic and benchmark targets. |
| `attribution-modeler` | agent | Multi-touch attribution choices (first/last/linear/U-shape/time-decay), self-reported vs deterministic, with cost-of-being-wrong analysis. |
| `seo-aeo-geo-strategist` | agent | Topical authority maps, AEO content blocks, GEO/LLM answer-engine plays, schema strategy. |
| `channel-benchmark-library` | skill | CAC/CTR/conv benchmarks by channel/vertical (Meta, LinkedIn, Google, SEO, partnerships, community). |
| `funnel-math` | skill | Conversion math, payback math, magic-number math, paid-to-organic ratio targets. |
| `community-led-distribution` | skill | Founder-led distribution playbook: communities, narrative, content cadence, partner ecosystems. |
| `lifecycle-trigger-library` | skill | Reusable trigger conditions and message templates for onboarding/activation/retention/winback. |
