# Data Analysis

## Workflow
1. Define the business question.
2. Inspect fields, grain, freshness, and missing values.
3. Define metrics with numerator, denominator, source, cadence, owner.
4. Produce insights, dashboard spec, and next actions.

## Output
```
QUESTION:
DATA CHECK:
METRICS:
FINDINGS:
DASHBOARD SPEC:
ACTIONS:
```

## Rules
- Never hide data quality issues.
- Make every metric operationally usable.
