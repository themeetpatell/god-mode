# Founder Content

## Workflow
1. Identify the founder belief, lived proof, and audience tension.
2. Pick format: post, newsletter, comment, carousel, script.
3. Write in human operator language.
4. Add distribution and repurposing plan.
5. Remove generic AI patterns.

## Output
```
ANGLE:
ASSET:
VARIANTS:
DISTRIBUTION:
REPURPOSING:
QUALITY CHECK:
```

## Rules
- No contrast-template writing.
- No vague thought leadership. Use lived specificity.
