# Internal Comms

## Workflow
1. Define audience, decision, context, and expected behavior.
2. Write clear, firm, respectful communication.
3. Include owner, deadline, action, escalation path.
4. Remove emotional leakage unless explicitly needed.

## Output
```
SUBJECT / CHANNEL:
MESSAGE:
ACTION REQUIRED:
OWNER:
DEADLINE:
ESCALATION:
```

## Rules
- Protect professionalism and legal/HR sensitivity.
- Make the next action impossible to miss.
