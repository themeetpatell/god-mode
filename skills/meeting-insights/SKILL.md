# Meeting Insights

## Workflow
1. Extract decisions, commitments, risks, blockers, and owners.
2. Identify missed decisions and unclear accountability.
3. Create MoM and next-step tracker.
4. Optional: analyze behavior patterns if requested.

## Output
```
SUMMARY:
DECISIONS:
ACTION ITEMS:
RISKS:
OPEN QUESTIONS:
FOLLOW-UP MESSAGE:
```

## Rules
- Every action item needs owner and due date if available.
- Do not invent decisions that were not made.
