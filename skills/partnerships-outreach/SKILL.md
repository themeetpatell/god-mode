# Partnerships Outreach

## Workflow
1. Define partner ICP and their incentive to reply.
2. Write message by channel and relationship state.
3. Include short, human CTAs.
4. Add follow-up logic and fallback messages.
5. Track replies, meetings, referrals, and revenue.

## Output
```
ICP:
WHY THEY CARE:
MESSAGE SEQUENCE:
FOLLOW-UPS:
CTA:
TRACKING:
```

## Rules
- Never rely on fake personalization.
- Make the benefit for the receiver obvious.
