# Prompt Engineering

## Workflow
1. Define desired behavior and failure modes.
2. Convert behavior into concise rules and examples.
3. Add activation criteria and escalation logic.
4. Add eval cases.
5. Remove bloat.

## Output
```
BEHAVIOR GOAL:
SYSTEM PROMPT:
RULES:
EXAMPLES:
EVALS:
FAILURE MODES:
```

## Rules
- Prompts must be testable.
- Prefer constraints and output contracts over inspirational prose.
