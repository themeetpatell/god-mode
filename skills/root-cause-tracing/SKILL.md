# Root Cause Tracing

## Workflow
1. State the symptom precisely.
2. Build a timeline.
3. Trace backward through systems, data, people/process, and assumptions.
4. Separate trigger, root cause, contributing factors, and detection gap.
5. Produce prevention plan.

## Output
```
SYMPTOM:
TIMELINE:
ROOT CAUSE:
TRIGGER:
CONTRIBUTING FACTORS:
FIX:
PREVENTION:
MONITORING:
```

## Rules
- Do not stop at the first visible error.
- Every prevention action needs an owner and signal.
