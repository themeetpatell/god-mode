# UI / UX Conversion

## Workflow
1. Define target user, buying intent, and desired action.
2. Map current friction or design new page flow.
3. Structure page/flow sections around decision momentum.
4. Add proof, risk reversal, FAQs, CTA logic.
5. Provide implementation-ready IA.

## Output
```
USER INTENT:
FLOW:
SECTION STRUCTURE:
CONVERSION MECHANICS:
COPY NOTES:
DESIGN NOTES:
TRACKING:
```

## Rules
- Every section must earn its place.
- Design for clarity, speed, trust, and action.
