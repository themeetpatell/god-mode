# Webapp Testing

## Workflow
1. Identify critical user journeys.
2. Validate UI states: loading, success, empty, error, permission denied.
3. Test mobile/desktop and slow network assumptions.
4. Capture bugs with reproduction steps.
5. Produce release verdict.

## Output
```
CRITICAL FLOWS:
TEST MATRIX:
BUGS:
REPRO STEPS:
AUTOMATION PLAN:
RELEASE VERDICT:
```

## Rules
- Test what directly affects conversion, trust, onboarding, and data integrity first.
